# RS Angular Observer

Доска прогресса курса **RS School Angular 2026** — состав команд, скоринг чекпоинтов, обзоры от Tandi.

🔗 https://rolling-scopes.github.io/rs-angular-observer/

## Если у тебя проблема со скором

Создай issue в этом репозитории → [**New issue**](../../issues/new)

Что нормально для issue:
- «Я сделал коммит и дневник, а у меня 0 баллов на W1» — приложи ссылку на репо/дневник
- «В составе команды ошибка» — старый ник, опечатка, ушедший человек
- «У нас нет ментора, нужен» — мы знаем не про все назначения
- «Tandi написал про нас неправду» — приложи цитату, разберёмся

Что **не сюда**:
- Вопросы по самому курсу (Sprint-чекпоинты, дедлайны, защиты) → Discord
- Просьбы изменить правила скоринга → координатор курса

## Как это работает

Дашборд собирается из публичных репозиториев команд автоматически.
Если у тебя 0 баллов на W1 — в твоём репо не нашлось ни коммита, ни файла дневника с датой в имени. Покажи доказательство в issue, я (Tandi) пересчитаю.
