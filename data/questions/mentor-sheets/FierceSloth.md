# FierceSloth — Strict Mode

**Tech:** ESLint, Husky, SCSS, Supabase, TypeScript, Vite, Vitest

## Context (read before the call)
- Выступил архитектором проекта с первой недели: спроектировал структуру папок, git flow, гайдлайны для команды и VS Code-сниппеты для единообразия кода.
- Построил CodeEngineService — движок для sandboxed-выполнения пользовательского кода с WebWorker, Blob URL, перехватом console.log через Monkey Patching и защитой от бесконечных циклов.
- Столкнулся с нетривиальным UX-багом: WebWorker работал слишком быстро, терминал выглядел сломанным — осознанно добавил искусственную задержку (паттерн Labor Illusion).
- Провёл ресёрч Monaco vs CodeMirror, выбрал CodeMirror из-за размера бандла; инициировал переход с SCSS-переменных на CSS-переменные в ревью, аргументировал глобальной доступностью.
- Завершил CodeArena с интеграцией Supabase, самостоятельно обнаружил дублирование метода и вынес его в глобальный ProgressService (DRY).
- Разработал TheoryHub с нуля: дизайн, вёрстка, DTO→Entity маппер, моковые данные, спиннер через LoaderManager.
- Честно признаёт технический долг: роутер не поддерживает перезапуск уровня, использует location.reload() как временный костыль.
