## Context (read before the call)
- Реализовала AI explain-agent модуль с нуля без опыта работы с AI — выбрала Groq, самостоятельно изучила API и спроектировала двухролевую систему (разные сценарии для правильных и неправильных ответов).
- Спроектировала двухуровневую архитектуру состояния (логическое состояние квиза + UI-состояние) после того, как осознала, что разрозненный подход к управлению кнопками перестал масштабироваться.
- Декомпозировала экран квиза на независимые модули (quizSelection, quizCheck, setupCheckLogic) — каждый не знает о состоянии остальных.
- Рецидивирующая проблема на всём проекте: функции росли неконтролируемо, а рефакторинг с помощью Copilot поначалу ухудшал ситуацию — приходилось разбираться вручную шаг за шагом.
- Самостоятельно обнаружила accessibility-проблему и переключилась с кнопок на radio inputs ради поддержки скринридеров.
- В начале проекта была заблокирована отсутствием прав maintainer для GitHub Project — трекинг задач пришлось перестраивать.
- На финальной неделе работала над фичей блокировки навигации во время квиза (защита от подглядывания ответов) — фича в процессе.
