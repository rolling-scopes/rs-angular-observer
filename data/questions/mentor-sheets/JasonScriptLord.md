# JasonScriptLord — Typocalypse

**Tech:** Husky, NestJS, Tailwind, Vite, Zustand

## Context (read before the call)
- Фронтенд-разработчик в команде с NestJS-бэкендом; начинал проект с почти нулевым опытом на React — учился в процессе.
- Взял на себя настройку инструментария с самого старта: Husky, linter, prettier.
- Реализовал UX-полировку: динамические лейблы в кнопках во время API-запросов ('Signing in...', 'Saving...').
- Построил standalone-компонент для отображения отсутствия сети — отдельная забота об офлайн-сценарии.
- Использует Zustand для глобального состояния; добавлял новые стейты по мере роста фич (loading flags для API).
- На последней неделе только планирует заняться дашбордом с бэкендом — интеграция фронт/бэк, похоже, ещё не завершена.
- Стек: React + Vite + Tailwind + Zustand (фронт), NestJS (бэкенд у коллег).
