# imagineapril — Алекс и его друзья

**Tech:** CSS Modules, Canvas, JWT, PostgreSQL, React, Tailwind, TypeScript, Vitest, Zustand

## Context (read before the call)
- Единственный фронтенд-разработчик в команде: бекенд и AI-агент делали две другие участницы, imagineapril отвечала за весь клиент.
- Начала проект с минимальным знанием React — первую неделю параллельно осваивала компоненты, хуки и роутинг.
- Построила полный фронтенд: лендинг, авторизацию, виджеты, Dashboard со статистикой и прогрессом, интеграцию с бекендом через React Query.
- Несколько недель потратила на попытки сгенерировать 3D-фигуру программиста через AI-инструменты — в итоге отказалась от Canvas и перешла на SVG-анимации.
- Самостоятельно решала реальные проблемы интеграции: бесконечный цикл useEffect при обновлении streak (починила через useRef), NaN в прогрессе при отсутствии totalLevels от бекенда.
- Сделала осознанный переход от FunctionComponent к обычным пропсам, разобравшись, почему FunctionComponent считается устаревшим.
- Использовала AI-инструменты активно, включая генерацию стилей по UI-киту — умеет рефлексировать над результатами и отказываться от неудачных подходов.
