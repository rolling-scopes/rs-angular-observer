## Context (read before the call)
- Взял на себя продуктовую роль на старте: провёл целую ночь проектируя UX, роутинг на 10+ маршрутов и макеты — команда приняла его архитектуру за основу.

- Работает с Redux Toolkit + RTK Query — освоил паттерн API slice (запросы и мутации в одном месте), сравнивал с TanStack Query.
- Нашёл практический инсайт про роутинг: использование `replace` при редиректе убирает возможность вернуться назад на страницу логина.
- Поставил инфраструктуру проекта с нуля: Vite + TypeScript, ESLint, Prettier, Husky pre-commit хуки, Vitest с coverage.
- Последние задачи — реализация компонентов Header и Breadcrumbs, запись checkpoint-видео.
