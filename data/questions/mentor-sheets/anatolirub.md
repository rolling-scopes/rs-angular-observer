**Tech:** Angular, Docker, MongoDB, PostgreSQL, Supabase, Vercel

## Context (read before the call)
- Провёл самостоятельный технический спайк: руками попробовал три бэкенд-стека (NestJS+Docker+MongoDB, Firebase, Supabase) за 1–2 сессии, чтобы аргументированно предложить команде решение
- Задеплоил Supabase на собственный VPS: купил два хостинга (первый не поддерживал Docker), настроил Docker, nginx и env через gitbash+nano — суммарно около 10 часов
- Обнаружил системное ограничение Supabase: password reset автоматически логинит пользователя при редиректе, что делает невозможным сценарий 'разлогин → смена пароля' — потратил значительное время до осознания невозможности
- Реализовал полный auth flow на Angular: email/password, Google, GitHub — с guards и interceptors
- Сравнил signal-based Forms API в Angular с классическим FormBuilder и осознанно остановился на классическом подходе как более надёжном
- Основной backend-исследователь в команде; Firebase отклонён из-за плотной привязки к Google-экосистеме
- Работал через несколько отладочных марафонов с явной эмоциональной нагрузкой — фрустрация нарастала, но студент продолжал двигаться и документировать выводы
