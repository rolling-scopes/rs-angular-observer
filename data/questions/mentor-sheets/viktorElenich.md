**Tech:** ESLint, Express, Groq, TypeScript

## Context (read before the call)
- Единственный backend-разработчик в команде — самостоятельно поднял весь бэкенд: Express + TypeScript + Swagger + AI-стриминг + управление сессиями за первую неделю.
- Сознательно следовал паттерну 'Data Contracts First': сначала опубликовал Swagger-документацию, чтобы фронтенд-коллеги не ждали готового API.
- Намеренно переписал интеграцию с groq-sdk на нативный fetch, чтобы соответствовать критерию Raw LLM API — осознанный trade-off, не технический долг.
- Архитектурные паттерны по собственной инициативе: PromptBuilderService (разделение ответственности), Mock Mode для независимой разработки, Single Source of Truth для словарей.
- Дважды попал в одну и ту же ловушку с YAML-отступами в swagger-jsdoc; дважды терял время на 'баг в коде', который оказался зависанием IDE — паттерн повторных ошибок.
- Нетривиальный инсайт про стриминг: понял, что нельзя сохранить ответ AI при стриминге чанками — нужно накапливать параллельно с отправкой клиенту.
- Планирует пивот с обычного чата на 'AI Judge' — систему с эталонными ответами и оценкой пользователя.
