**Tech:** Husky, TypeScript, Vercel, Vite, Vitest, Zustand

## Context (read before the call)
- Пришла в проект, изучая React практически с нуля, но стала первой в команде, кто поднял роутер и выстроил архитектуру компонентов.
- По собственной инициативе создала флоу-чарт, документ со структурой проекта и подробный README — никто не просил.
- Потратила значительное время на отладку dev-окружения: Biome не запускался на коммит автоматически, затем CRLF-конфликты из-за EditorConfig.
- На последнем этапе реализовала страницу 500, кастомный CSS-спиннер (без библиотек), глобальный стейт загрузки и обёртку через TanStack.
- Параллельно работает над стором статистики, интеграцией с дашбордом и хранением данных виджетов в базе.
- Работала 3–7 часов в день, совмещая с воспитанием ребёнка и хроническим недосыпом — темп не падал всё 6 недель.
- Стек: React + TypeScript + Zustand + TanStack, сборка Vite, тесты Vitest, деплой Vercel, git-хуки Husky.
