# hamsterk — Tuple Trouble

**Tech:** Canvas, Jest, Next.js, React, Render, Tailwind, TypeScript

## Context (read before the call)
- Пришёл в проект с нулевым опытом React и Next.js — самостоятельно прошёл базовый курс (~7 часов) в первую неделю и сразу начал контрибьютить.
- Предложил 6 детально проработанных концептов виджетов с полными спецификациями: ракетная игра с физикой, граф Big O, drag&drop сортировка кода — всё с описанием data contracts и UX-флоу.
- Реализовал landing page, 404-страницу, animated-counter и Learning widget с flip-анимацией.
- Столкнулся с несовместимостью сторонней библиотеки flip-карточек с React 19 — решил проблему самостоятельно, написав кастомную CSS-анимацию вместо библиотеки.
- Самостоятельно нашёл и исправил баг пикселизации canvas через devicePixelRatio; также боролся с проблемой SSR в Next.js, блокирующей применение CSS-переменных в canvas.
- Попытка сделать canvas bubble animation для лендинга не удалась эстетически — сам принял решение отказаться от подхода.
- На момент последней записи flip-card виджет ещё не доведён до исходного задуманного поведения после интеграции в widget runner.
