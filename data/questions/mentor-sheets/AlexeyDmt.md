# AlexeyDmt — RainbowUnicorn

**Tech:** JWT, React, SCSS, TypeScript, Vitest, Zustand, i18n

## Context (read before the call)
- Спроектировал систему i18n с нуля: namespace-структура, переключение языка, хранение в localStorage и на бэке, блокировка смены языка во время активного квиза.
- Разработал унифицированную TypeScript-архитектуру типов для всех типов квизов: discriminated union по полю `type`, разделение на универсальные и кастомные интерфейсы — контракт между фронтом и бэком.
- Нашёл и починил кросс-браузерный баг: Chrome возвращает `'en'`, Firefox — `'en-US'` через navigator.language; решение — нормализация через split('-')[0].
- Адаптировал всю структуру данных квизов под билингвальность — каждый вопрос, вариант ответа, title и description теперь объект `{ ru, en }`; финальный JSON отправлен на бэк.
- Потратил несколько сессий на генерацию тестовых вопросов через 4 разных AI-инструмента (ChatGPT, Claude, Алиса, Gemini) — у каждого свои поломки: смещение правильных ответов к варианту A, обрывы, лимиты токенов.
- Проактивный: подбирал незакреплённые задачи, инициировал командные обсуждения API-контракта, синтезировал предложения тиммейтов в итоговое архитектурное решение.
- Квизовый движок: вопросы рендерятся по одному, ответы копятся на фронте, отправляются пачкой, сервер хранит правильные ответы и возвращает результаты.
