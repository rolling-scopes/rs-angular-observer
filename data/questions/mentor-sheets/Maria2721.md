# Maria2721 — DevCraft

**Tech:** GitHub Actions, Netlify, React

## Context (read before the call)
- Тимлид команды с первого дня: создала оба репозитория (фронт и бэк), Kanban-доску, README, вела командные созвоны и координацию с ментором на протяжении всех 6 недель.
- Проект — платформа для подготовки к собеседованиям; ключевая UI-фича — интерактивная roadmap-визуализация на ReactFlow с дополнительным sidebar-списком как fallback для навигации.
- Настроила деплой фронтенда на Netlify через GitHub Actions — одна из первых инфраструктурных задач в проекте.
- На поздних неделях взяла фичу AI-ассистента: Redux slice, модалка-чат, доступ только для авторизованных пользователей (остальные редиректятся на login).
- Планировала подключить реальный AI API для чата — на момент последней записи модалка готова, интеграция с сетью ещё впереди.
- Активно использовала GitHub-инфраструктуру: отдельные репо для фронта и бэка, feature-ветки, PR-workflow — с самого старта проекта.
- Роль в команде — больше организационно-техническая: дизайн-ресёрч, сбор макетов, фасилитация технических решений, а не только написание кода.
