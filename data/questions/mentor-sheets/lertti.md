# lertti — Dev Journey

**Tech:** CI/CD, ESLint, Express, GitHub Actions, Husky, Jest, MongoDB, NestJS, Netlify, Node.js, Redux, Vitest, Zustand, i18n

## Context (read before the call)
- Основной вклад в проект — три D3.js ring-чарта для Dashboard: анимации attrTween, bounce-эффекты, последовательное появление сегментов, tooltips-синглтон, ResizeObserver для адаптивного перерисовывания.
- Самостоятельно применила паттерн Adapter для нормализации данных из разных источников и проактивно заложила расширяемость через Strategy — без задания от команды.
- Повторяющаяся проблема на протяжении всего проекта: забывала делать pull перед коммитом, несколько раз почти ломала PR тиммейта, чинила через force-push.
- ResizeObserver вызвал коллапс чартов до крошечных размеров из-за конфликта с flexbox — разбиралась самостоятельно.
- Параллельно проходила курс Node.js (Codecademy), самостоятельно изучала FRP и CI/CD — инициатива сверх программы.
- Публично возражала против оверинжиниринга (createHTMLElement) на командной встрече, прояснила смысл 'widget' в FSD для всей команды — взяла на себя роль технического арбитра.
- Команда использует FSD; были долгие (2.5 ч) обсуждения архитектуры, которые оставляли больше вопросов, чем ответов.
