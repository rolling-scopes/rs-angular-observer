# oneilcode — RSSAgents

## Context (read before the call)
- Разработала WidgetConsole — ключевой компонент проекта, потратив 10-12 часов в одну сессию на изучение Mantine с нуля и эксперименты до стабильной реализации.
- По итогам PR review освоила и применила сразу несколько продвинутых React-паттернов: AbortController для отмены fetch при анмаунте, useCallback для мемоизации, вынос логики в кастомные хуки, RequestInit typing.
- Активно участвовала в проектировании UX виджета: input field vs drag-and-drop, фиксированный уровень сложности vs градуированный — решение явно принималось в команде.
- Столкнулась с хрупкостью тестового покрытия: добавление любой фичи (например, лоадера) ломало тесты, написанные другими разработчиками.
- Для быстрого исправления чужих тестов использовала AI-инструменты — точка для разговора о зонах ответственности и понимании кода.
- Бэкенд реализован; следующий шаг по плану — рефакторинг API-слоя на фронтенде.
- Стартовала работу с анализа ТЗ, составления чек-листа требований и макетирования главной страницы — методичный подход к старту.
