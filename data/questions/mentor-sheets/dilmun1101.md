# dilmun1101 — Strict Mode

**Tech:** ESLint, Husky, SCSS, Supabase, TypeScript, Vite, Vitest

## Context (read before the call)
- Занималась бэкенд-интеграцией впервые — изучала Supabase и всю тему аутентификации с абсолютного нуля, без предыдущего опыта.
- Команда осознанно выбрала Supabase вместо Firebase Auth+Firestore: больше бесплатных возможностей, не нужны дополнительные Google-сервисы.
- Потратила целую неделю (10+ часов) на изучение теории auth — access/refresh токены, httpOnly cookies, разница регистрации и аутентификации — но столкнулась с классическим разрывом теория/практика: понимала концепции, но замирала при реализации.
- Удаляла нерабочий контроллер и начинала заново; признаёт, что временами блокировала команду, пока база данных не была готова.
- Открыла для себя готовые редакторы кода (Monaco/CodeMirror) как решение задачи code editor — первый опыт интеграции тяжёлой UI-библиотеки.
- Прошла через рефакторинг компонентов — сначала сделала большой монолитный компонент виджета, потом разбила на карточки, хедер и сборочный контейнер.
- На последней неделе работала над контроллерами для 'output predictor' и базой данных для обучающего модуля 'intro' — проект включает несколько сложных составных фич.
