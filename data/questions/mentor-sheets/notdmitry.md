# notdmitry — Gang of Four

**Tech:** CI/CD, ESLint, GitHub Actions, Material UI, Netlify, React, TypeScript, Vercel, Vite

## Context (read before the call)
- Тимлид команды — лично настроил весь инфраструктурный фундамент: репозиторий, защиту веток, CI/CD на GitHub Actions + Netlify, AppRouter и первый релиз с semantic versioning.
- Попал в классическую ловушку: начал проектировать данные с реляционными допущениями, затем обнаружил, что Firebase Firestore — NoSQL, и пришлось переосмыслить всю модель данных и контракт с фронтендом.
- Принял ряд взвешенных архитектурных решений: отверг FSD из-за высокого порога вхождения для команды, выбрал Git Flow вместо GitHub Flow (отсутствие тестов как обоснование), Netlify вместо GitHub Pages после проблем с baseUrl.
- Временно заткнул проблему типизации конфигов виджетов через `never` — сам признаёт, что это не финальное решение.
- Едва не сломал main: вёл дневники в отдельной ветке, что привело к конфликту и потребовало пересоздания записей вручную.
- Параллельно с тимлидством и помощью коллегам в освоении React — готовился к собственному собеседованию на работу.
- На финальном этапе — ждёт PR от тиммейта для интеграции Firebase-бэкенда с двумя виджетами и сборки рабочей версии.
