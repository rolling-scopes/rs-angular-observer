# Webis-2022 — DevBand

**Tech:** ESLint, Husky, Supabase, TypeScript, Vite, Vitest, Zustand

## Context (read before the call)
- Де-факто техлид команды: единолично поднял весь инфраструктурный стек (TypeScript, ESLint, Vite, Sass, Husky, Vitest, Prettier) с нуля и спроектировал масштабируемую структуру папок.
- Спроектировал и реализовал интеграцию с Supabase: схема БД, RLS-политики, edge function с вызовом LLM для динамической генерации вопросов.
- Критический баг: отсутствие RLS-политики на таблице game_results приводило к тихим ошибкам сохранения — данные молча не писались в БД.
- Нарушение SRP в функции saveProgress (смешаны DOM, бизнес-логика и Supabase-вызовы) — поймано на code review, после чего отрефакторено.
- Фиксировал 15–20-часовые рабочие недели, параллельно тянул координационную нагрузку по команде.
- Активный ревьюер: регулярно делал code review PR коллег, часть багов обнаружил именно через этот процесс.
- Последняя неделя: сохранение результатов игры в стейт и БД, фикс бага в edge function (отсутствие проверки уровня сложности перед вызовом LLM), начало работы над Dashboard.
