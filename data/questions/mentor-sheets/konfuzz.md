# konfuzz — Devtones

**Tech:** Canvas, Express, Husky, JWT, OpenAI API, Pinia

## Context (read before the call)
- Инициатор и лидер команды: предложил концепцию приложения (платформа для подготовки к собеседованиям с виджетами), создал репозиторий, настроил branch protection, канбан-доску, сделал Figma-макеты.
- Построил работающий прототип CSS Battle (html-to-canvas + попиксельное попиксельное сравнение) ещё до командного решения — намеренно, чтобы проверить техническую реализуемость и найти подводные камни (CSS scope leakage, надёжность pixel diff).
- Провёл масштабное эмпирическое исследование OpenRouter: перебор десятков моделей, изучение tool calling, сотни итераций промптов — нашёл модель с нужным поведением.
- Несколько дней отлаживал LLM tool calling — пытался получить текстовый фидбек и числовую оценку в одном ответе; все попытки провалились, применил workaround; самостоятельно описал ситуацию как 'бессилие работы с чёрным ящиком'.
- Провёл конкретный эксперимент с размером бандла: пустой Vue vs Vue + PrimeVue datatable — разница +500KB за один компонент, итог повлиял на выбор UI-библиотеки.
- Реализовал JWT-аутентификацию (Express backend) и ввёл Pinia для управления состоянием авторизации, когда localStorage оказался неудобен для реактивности.
- Вся команда работала с Vue впервые — осознанный командный риск, принятый с открытым обсуждением последствий.
