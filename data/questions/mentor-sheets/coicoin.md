# coicoin — Strict Mode

**Tech:** ESLint, Husky, SCSS, Supabase, TypeScript, Vite, Vitest

## Context (read before the call)
- Написал кастомный SPA-роутер с нуля на ванильном TypeScript: HistoryAPI, парсинг params и query, аналоги useNavigate/useParams, защищённые страницы, replaceState и navigate(-1) — по сути пересобрал ядро React Router без библиотек.
- Поймал нетривиальный баг: location.pathname не включает query string, пришлось конкатенировать pathname + location.search и протащить фикс сквозь весь HistoryAPI-слой.
- Столкнулся с ограничением компилятора SCSS: var() нельзя вычислить в момент компиляции как аргумент миксина, пришлось отказаться от font-миксина.
- Участвовал в командном архитектурном решении: SCSS-переменные vs CSS-переменные vs preprocessorOptions в vite.config.ts — осознал преимущества CSS-переменных для глобальной темизации.
- Самостоятельно мигрировал проект с устаревшего @import на @use по рекомендациям Sass.
- Работал над UI-функционалом (header, TrueFalsePage с блоком вопросов), столкнулся с проблемой центрирования из-за сторонней библиотеки.
- Провёл код-ревью PR коллеги по команде, тратил 8-часовые сессии на роутер.
