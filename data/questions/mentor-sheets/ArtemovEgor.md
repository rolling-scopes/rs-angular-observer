## Context (read before the call)
- Тимлид команды из трёх человек: с первого дня взял на себя настройку репозитория, CI/CD (GitHub Actions + Docker) и базовую архитектуру проекта.
- Написал кастомный SPA-роутер с нуля: поддержка модальных окон поверх страниц, query-параметры, прямые ссылки и корректная обработка перезагрузки страницы.
- Спроектировал систему авторизации с абстрактным базовым классом для форм Login/Registration — убрал дублирование; потратил 7+ часов в один день; финально добавил обработку истёкшего токена (401) через проверку кэша.
- Разработал 3-шаговый AI-воркфлоу для дизайна всей команды (Claude Opus → ручная правка → NanoBanana → макеты), результат — спецификация на 400 строк, принятая командой.
- Два других участника — PHP-бэкендеры, переключившиеся на Node.js; студент координировал архитектурные решения и брал на себя непредсказуемые по сложности задачи (AI-чат).
- Потерял несколько часов на merge-конфликты при слиянии параллельных UI и API веток; сам поймал себя на scope creep в середине задачи.
- Сформулировал личный фреймворк из 3 правил работы с AI-инструментами: разбивать на мелкие шаги, формулировать промпт до решения, всегда проверять за моделью.
