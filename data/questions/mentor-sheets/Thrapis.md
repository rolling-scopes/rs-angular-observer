# Thrapis — Auto-Team 5

**Tech:** CI/CD, ESLint, GitHub Actions, Groq, Nuxt, Pinia, Supabase, Tailwind, Vercel, Vite, Vue

## Context (read before the call)
- Де-факто технический лидер в команде без явного лида — взял инициативу с первого дня, включая выбор стека и архитектуры.
- Обнаружил mid-project, что команда концептуализировала SSR-приложение, но инициализировала обычный Vue SPA — единолично мигрировал весь проект на Nuxt.
- Предложил и внедрил FSD (Feature Sliced Design) архитектуру, добился её принятия командой.
- Построил Repository pattern с Dependency Injection и mock-реализациями для тестирования.
- Настроил GitHub Actions CI/CD; обнаружил и починил баг с кешированием, который молча пропускал установку ESLint/Prettier.
- Интегрировал AI API (Groq) с контролируемым форматом вывода через поле instructions — исследовал самостоятельно через Go-прототип до командного созвона.
- Автор полного комплекта UML-документации (Use Case, Activity, Sequence, DB); несколько сессий по 7–13 часов подряд.
