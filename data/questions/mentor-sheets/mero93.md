# mero93 — Tuple Trouble

**Tech:** Next.js, Supabase, Zustand, i18n

## Context (read before the call)
- Пришёл в проект с Angular-бэкграундом — намеренно использовал знакомую архитектуру как мост для изучения Next.js, в том числе через AI-сравнения двух фреймворков.
- Реализовал i18n самостоятельно на Zustand вместо стандартной библиотеки: глобальный реестр строк, два хука (для UI-текстов и для данных БД), локаль хранится в cookies и читается при инициализации стора.
- По ходу проекта сменил подход к i18n с серверного (LocaleProvider) на полностью клиентский — решение принято после тестирования.
- Строит сложную CRUD-панель администратора для сущностей Topic / Widget / Question с вложенными связями (topic_widget как промежуточная таблица), модальными окнами и предупреждениями при каскадном удалении.
- Проектирует обобщённую систему форм: CustomForm выводит тип поля из Zod-схемы, CustomSelect работает с enum-ами и массивами, поддерживает single/multi-режим.
- Прогресс стабильно замедлялся из-за параллельного курса и подготовки к собеседованиям — сам признаёт это в дневнике, план работ часто сдвигался.
