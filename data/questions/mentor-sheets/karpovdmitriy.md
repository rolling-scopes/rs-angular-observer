# karpovdmitriy — Джунгли зовут!

**Tech:** ESLint, PostgreSQL, React, Supabase, TypeScript

## Context (read before the call)
- Тимлид команды: единолично настроил всю инфраструктуру проекта — репо, Trello с GitHub-интеграцией (решил нетривиальный баг подключения), ESLint/Prettier/Stylelint, branch protection, PR-шаблон, CI — всё с первой попытки.
- Провёл глубокое сравнение BaaS-решений (Supabase vs Firebase vs Appwrite), выбрал Supabase из-за PostgreSQL-основы и реляционной модели; задокументировал решение в дневнике.
- Самостоятельно спроектировал схему базы данных для 4 типов виджетов, построил API-слой с Supabase triggers и синхронизацией auth-состояния между вкладками.
- Реализовал 'движок виджетов' на паттерне Strategy — центральная фича приложения (тренажёр с разными типами карточек и подсчётом финальной статистики).
- Сделал страницу Library (каталог тестов с фильтрацией и запуском) — частично с помощью AI-ассистента.
- Drag-and-drop к финалу не доделан; основной блокер — нехватка времени в последние недели.
- Открыл для себя, что Supabase даёт auth из коробки (не нужны кастомные таблицы пользователей) и что PR-шаблон активируется GitHub только после мержа в default branch.
