# mvavilin — Nova

**Tech:** ESLint, Render, Tailwind, TypeScript, Vercel, Vite, Vitest

## Context (read before the call)
- Тимлид команды Nova: взял на себя всю архитектурную подготовку — монорепозиторий, окружение, концепт игры, Figma-макеты — пока остальные только входили в проект.
- Самостоятельно настроил Turborepo-монорепозиторий (новая технология для него) с полным frontend-окружением: Vite, Tailwind, ESLint+Unicorn, Prettier, Vitest, lint-staged, tsconfig с path aliases.
- Исследовал два варианта деплоя (Render для всего vs Render-сервер + Vercel-клиент), оформил оба как черновые PR для командного обсуждения.
- Проект — мультиплеерная игра Codenames (Nova-Codenames) с WebSocket-архитектурой: клиент и сервер в одном монорепозитории.
- На последней неделе работал над страницей игры (три модальных окна), ждал готовности сокет-событий на сервере для подключения логики.
- Планировал добавить reconnect-логику, переводы (i18n), тесты к компонентам и рефакторинг перед презентацией.
- Осознанно рефлексировал о командной работе: отметил, что код-ревью и ежедневные обсуждения дают не меньше роста, чем самостоятельное изучение технологий.
