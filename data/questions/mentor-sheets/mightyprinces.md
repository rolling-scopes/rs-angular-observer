# mightyprinces — RainbowUnicorn

**Tech:** React, Render, Vitest

## Context (read before the call)
- Разрабатывала React-приложение с drag-and-drop механикой — несколько «заданий», между которыми можно переключаться.
- Стек: React + Render (деплой) + Vitest (тесты); вся команда договорилась использовать Material Design для единообразия.
- Material Design — новый инструмент для студентки: изучала с нуля через документацию, YouTube и Figma-прототипы.
- Реализовала умную логику активации кнопки «следующее задание»: кнопка загорается только если элемент реально переместился, а не просто перетащили и вернули обратно.
- Сделала сохранение результатов перетаскиваний между страницами/заданиями.
- Начинала с дизайна — создала в Figma экраны логина/регистрации из компонентов Material Design со всеми состояниями полей и ошибками.
- Судя по дневникам, работала методично: исследование → прототип → реализация — без видимых катастрофических блокеров.
