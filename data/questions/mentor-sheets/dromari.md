# dromari — Джунгли зовут!

**Tech:** Jest, React, Supabase, Vitest, i18n

## Context (read before the call)
- Пришла в проект с нулевым опытом React — учила фреймворк в параллель с написанием продакшн-фич, работала по 8–20 часов в день.
- Построила систему глобальной обработки ошибок (Toast-компонент) с нуля, без UI-библиотек.
- В середине проекта прошла через полный рефакторинг архитектуры вместе с ментором: мигрировала на CSS-модули, вынесла константы, добавила хуки.
- Дважды случайно коммитила две фичи в один коммит; позже самостоятельно усвоила принцип «одна задача — один коммит».
- Столкнулась с блокирующим PR-bottleneck: зависимые фичи не могли продолжаться, пока предыдущие PR не смёрджены.
- Проактивно открыла 5 GitHub Issues до того, как узнала, что это требование чекпоинта — обнаружила это постфактум.
- Стек проекта: React + TypeScript, Supabase, i18n, Jest/Vitest; AI-ассистированное обучение создавало трение из-за несовместимости JS-примеров с TS.
