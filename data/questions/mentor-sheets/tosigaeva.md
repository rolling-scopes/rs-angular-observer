# tosigaeva — Tuple Trouble

**Tech:** ESLint, GitHub Actions, Husky, Next.js, React, Render, Tailwind, TypeScript, Vercel

## Context (read before the call)
- В самом начале проекта единолично настроила всю инфраструктуру за один день: GitHub Actions с параллельными джобами, ESLint + Prettier + Husky + lint-staged, branch protection, деплой на Vercel.
- Спроектировала и реализовала Widget Engine на основе Strategy Pattern с динамической загрузкой компонентов в Next.js.
- Самостоятельно оценила Biome как замену ESLint+Prettier, но пришлось откатиться — правила проекта требовали стандартного стека.
- Столкнулась с конфликтом строгих правил ESLint (strict-boolean-expressions, no-null) и библиотечных компонентов shadcn/ui — решила через отключение правил для папки ui/.
- Прошла путь от Strategy Pattern по документации до понимания границы server/client компонентов в Next.js — пришла к лучшим практикам через ошибку.
- Сейчас работает над async sorter виджетом с drag-and-drop, подсветкой drop-зон и валидацией ответов — переписала логику проверки с correctAnswer-подхода на userAnswer-подход из-за edge cases.
- Судя по вкладу, фактически tech lead команды по инфраструктуре и архитектурным решениям.
