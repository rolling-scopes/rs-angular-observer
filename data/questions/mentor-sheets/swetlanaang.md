# swetlanaang — Gang of Four

**Tech:** Material UI, React, Vite, Vitest

## Context (read before the call)
- Пришла в проект с минимальным опытом React — до этого писала ванильный JS (RSS Puzzle), всё осваивала на ходу.
- Построила единый переиспользуемый компонент формы (Login/Register/Profile) через React Hook Form + Zod — с нуля по обеим библиотекам.
- Была единственным голосом против внедрения MUI в команде, аргументировала тем, что абстракция преждевременна — команда уступила, позже поменяла своё мнение.
- Провела полный день итерируя один Input-компонент; к концу третьей недели команда не написала продуктового кода — открыто выражала фрустрацию.
- Самостоятельно дошла до механизма reconciliation React: отлаживала stale-стили MUI после reset, решила инкрементом formKey для принудительного remount.
- Через болезненные код-ревью выучила паттерны ComponentPropsWithoutRef, PropsWithChildren, ReactNode — именно через ошибки, не из туториалов.
- Сейчас строит сложный виджет AsyncSorter (~250 строк TSX) с Drag and Drop между очередями; столкнулась со stale state в обработчиках событий.
