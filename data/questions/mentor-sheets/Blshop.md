# Blshop — CodePain

**Tech:** ESLint, Groq, Husky, React, TypeScript, Vite

## Context (read before the call)
- Тимлид команды CodePain — с нуля поднял весь инфраструктурный стек: Vite+React+TypeScript, ESLint, Prettier, Husky, CommitLint.
- Строит AI-powered квиз: исследовал интеграцию GROQ API для голосовых ответов с AI-оценкой — фича сверх базового задания.
- Реализовал модуль Quiz с динамической загрузкой вопросов, несколькими типами заданий, проверкой ответов, прогресс-баром и блоком объяснений.

- Испытывал трудности с пониманием чужого кода на React Router во время код-ревью — разобрался через документацию и AI.
- Совмещает роль тимлида (созвоны, координация, деплой) с активной разработкой новых фич.
