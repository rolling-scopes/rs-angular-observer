**Tech:** ESLint, GitHub Actions, Groq, Husky, Netlify, Render, SCSS, TypeScript, Vite, Vitest

## Context (read before the call)
- Тимлид команды Auto-Team 7: единолично поставила весь проект с нуля — Vite, TypeScript strict, ESLint, Prettier, Husky, CI/CD на GitHub Actions, деплой на Netlify.
- Проект Smart-Quiz — квиз по HTML/CSS/JS с выбором уровня и «explain mode»; стек включает Groq (AI API) и Render, что указывает на бэкенд-сервис (вероятно, для проксирования запросов к Groq).
- Намеренное решение: ванильный TypeScript SPA без фреймворка — обосновано ограниченным временем и размером команды.
- Повторяющаяся боль: деплой на Netlify падал из-за платформозависимого бинарника Rollup (linux-x64-gnu) — диагностировала сама, починила пересозданием lockfile и выравниванием версий Node.
- Активно ревьюила PR коллег с архитектурными комментариями, писала инструкции для команды, вела и модерировала все встречи.
- На момент последней записи работает над соединением компонентов Dashboard и Quiz: проектирует функцию-медиатор для кэширования загруженных данных квиза и исключения повторных запросов.
- Тестирование через Vitest; два хостинга (Netlify — фронт, Render — бэк) — в стеке присутствует и клиентская, и серверная часть.
