# t-gladkaya — SkillsZen team

**Tech:** Firebase, Husky, Netlify, React, Render, Tailwind, Vite, Vitest

## Context (read before the call)
- Фактически выполняла роль тимлида и архитектора одновременно: с первой недели взяла на себя весь инфраструктурный фундамент — Vite, Husky, Prettier, Tailwind, роутинг, shared-компоненты, адаптивность 320–1280px.
- В команде не было дизайнера — самостоятельно сгенерировала AI-фоны для приложения.
- Команда не нашла подходящий готовый API для квизовых задач и сознательно решила строить свой (Docker-based сервер).
- Проявила организационную инициативу: заранее настроила основную ветку разработки, чтобы команда могла работать параллельно без хаоса.
- Зафиксировала проблему нарастающего дублирования кода между компонентами, организовала командный созвон — но проблема оставалась нерешённой на момент записи.
- На поздних неделях провела рефакторинг: объединила три отдельные страницы (TS, JS, algo) в одну с общей логикой.
- Сейчас строит страницу для самопроверки по типам TypeScript — JSON-driven система карточек с переворотом.
