# Campidoc — TetraTeam

**Tech:** ESLint, Webpack

## Context (read before the call)
- Единолично поднял весь технический фундамент команды с нуля: репозиторий, webpack, ESLint, Prettier, TypeScript, CI/GitHub Actions — задокументировал каждый шаг в первую же неделю.
- Столкнулся с несовместимостью ESLint v10 и самостоятельно диагностировал и откатился до v8.
- Обнаружил нетривиальный баг окружения: PowerShell молча переключает кодировку UTF-8 → UTF-16, что ломало отображение символов в браузере.
- Разобрался с поведением HTTP 200 vs 303 при повторных запросах на задеплоенный сайт — в контексте проблемы с деплоем.
- Организовал code review процесс в команде: добавил всех участников ревьюерами уже в первом PR.
- В последние недели занимался написанием тестов (4 кейса на неделе 4) и разработкой игровой логики — проект называется TetraSkill.
- По всем признакам — технический лид команды; основная масса остальных участников к инфраструктуре не прикасалась.
