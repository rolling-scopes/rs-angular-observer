# Andrey-Yurchuk — DevCraft

**Tech:** Docker, ESLint, Express, GitHub Actions, Groq, Husky, JWT, Jest, NestJS, Node.js, OpenAI API, PostgreSQL, Prisma, Redux, SCSS, TypeScript

## Context (read before the call)
- Пришёл с PHP-бэкграундом (Doctrine, Eloquent), за 6 недель самостоятельно поднял NestJS-бэкенд с нуля — первый серьёзный Node.js проект.
- Начал с Express, потом в один день (9–10 часов) переключился на NestJS и задеплоил бэкенд с Docker + GitHub Actions CI/CD.
- Провёл формальное сравнение 8 архитектурных паттернов (Clean, Hexagonal, DDD, CQRS, MVC, Layered и др.), выбрал Clean Architecture с 4 слоями — с явной аргументацией.
- Реализовал AI-чат с подключаемым LLM-провайдером через Strategy + DI: провайдер переключается env-переменной без правки use case.
- В последние дни добавил интеграцию с Dify Chatflow (промпты редактируются без деплоя) и MCP-endpoint для Dify Tools.
- Столкнулся с каскадными деплой-фейлами в один день: SSH-ошибка libcrypto → диск на сервере заполнен → папка prisma/ отсутствует в финальном Docker-образе.
- Обнаружил, что TypeScript-интерфейсы стираются при компиляции и не работают как DI-токены в NestJS — перешёл на абстрактные классы.
