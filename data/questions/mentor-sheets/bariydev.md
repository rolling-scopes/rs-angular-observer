# bariydev — Devtones

**Tech:** ESLint, Husky, Tailwind, TypeScript

## Context (read before the call)
- Взял на себя всю инфраструктуру проекта: настроил ESLint Flat Config с плагином Perfectionist (автосортировка импортов), Prettier, Husky с lint-staged + vue-tsc и Conventional Commits — всё в один день, сознательно до написания фич.
- Работал над компонентом «конструктор методов» на Vue + PrimeVue — задача оказалась значительно глубже, чем выглядела, разбирался с экосистемой вплотную.
- Недавно провёл миграцию на монорепозиторий (объединил frontend и backend), разделил CI на два отдельных workflow и перевёл Husky на единый корневой `.husky` — устранил конфликты хуков.
- Чинил сложный стек ESLint для монорепозитория: добавлял eslint-import-resolver-typescript, настраивал исключение dist, правил VS Code settings чтобы линтер подхватывался из корня.
- Проект начинал с глубокого погружения в AI-инструменты (Qwen CLI, Gemini) — самостоятельно разобрался в разнице между вайб-кодингом и агентным программированием.
- Стек команды: Vue + TypeScript + Tailwind, с тяжёлым акцентом на инструменты качества кода с первого дня.
