## Context (read before the call)
- Взял на себя роль инфраструктурного участника команды: настроил весь tooling с нуля (Vite, ESLint, Prettier, Husky, commitlint) в первый же день
- Провёл самостоятельное исследование трёх бекенд-вариантов (n8n → Supabase → Firebase), консультируясь и с ментором, и с AI, прежде чем принять решение — выбрал Firebase
- Столкнулся с нетривиальным инфраструктурным багом: Vite создал проект в подпапке, Husky не срабатывал — пришлось переносить весь проект в корень репозитория
- Случайно закоммитил .env с живыми ключами Firebase до добавления в .gitignore — исправил через force push
- Настраивал Firebase вручную: создал отдельный Google аккаунт, сконфигурировал окружение, организовал передачу credentials команде
- В последние недели реализовал базовые UI-паттерны: страница 404, loading state, обработка ошибок API
- В стеке заявлены Zustand и Vitest, но дневниковых записей об их использовании почти нет — стоит уточнить глубину работы с ними
