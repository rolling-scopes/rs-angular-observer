# Igel-k — RainbowUnicorn

**Tech:** JWT, Material UI, PostgreSQL, Zustand

## Context (read before the call)
- Единственный backend-разработчик в команде — выстроила весь серверный стек с нуля в одиночку, пока остальные работали на фронтенде.
- Арендовала VPS на Ubuntu 22.04, установила PostgreSQL 16, самостоятельно разобралась с настройкой удалённого доступа (listen_addresses, pg_hba.conf).
- Развернула полный production-стек: Django + Gunicorn + Nginx через systemd, подключила SSL-сертификат через DuckDNS и связала GitHub Pages с backend по HTTPS.
- Реализовала JWT-аутентификацию с историей входов и кастомную модель пользователя Django — правильно применила правило 'до первых миграций'.
- Настроила CORS для связки фронтенда с backend и добавила регистрацию с валидацией паролей (первоначально принимались пароли типа '1' и 'admin').
- На последних неделях переключилась на разработку квизов: создаёт модели Django, сериализаторы, переносит данные в PostgreSQL (уже 4 квиза на сервере).
- Самостоятельно разобралась с доменной инфраструктурой, HTTPS и CORS — область, которая изначально не входила в её планы.
