# sabinabatrakova — Dev Journey

**Tech:** CI/CD, Husky, Netlify, Supabase, TypeScript, Vite, Vitest

## Context (read before the call)
- Взяла на себя CI/CD с нуля: самостоятельно разобралась с GitHub Actions, отладила два последовательных падения сборки (vitest/globals types и ESNext.Disposable в tsconfig) и настроила Netlify CD — всё за один сеанс.
- Отвечает за клиентский роутинг: auth guards через Supabase-сессии, редиректы /practice → /login, сохранение сессии при перезагрузке, 404-страница.
- Написала или использует кастомную routing-утилиту ('navigare') — планировала вынести её в shared, чтобы команда тоже могла переиспользовать.
- Стек: TypeScript + Vite + Vitest + Supabase + GitHub Actions + Netlify + Husky; работала в команде из 3–4 человек с распределёнными фичами и общим PR workflow.
- Незадолго до финала прошла внутренний JS/TS-интервью на 10/10 — видно, что старается подкреплять практику теорией.
- Стиль работы: высокая самостоятельность, рефлексия после ошибок, философский вывод ('бесконечная глубина — просто дышать'); дневники написаны вдумчиво.
