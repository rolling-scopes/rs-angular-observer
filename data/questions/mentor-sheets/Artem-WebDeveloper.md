# Artem-WebDeveloper — RainbowUnicorn

**Tech:** Material UI, React, Vitest, Zustand

## Context (read before the call)
- Тимлид команды без предыдущего опыта командной разработки — организовывал воркфлоу с нуля: ветки, структуру папок, архитектуру роутинга и защищённые маршруты.
- Построил полноценную страницу /library: адаптивная вёрстка (от 320px), пагинация, фильтрация, состояния загрузки и ошибок, edge-cases переполнения карточек.
- Инициативно добавил незапланированную фичу «Избранное» поверх основного скоупа.
- Провёл рефакторинг модуля фильтров — устранил потенциальную рассинхронизацию состояний.
- Учил Material UI прямо в процессе: хедер и футер заняли несколько дней вместо нескольких часов.
- Открыл useMediaQuery как замену ручным resize-листенерам и разобрался с sub-pixel рендерингом в CSS media queries.
- Стек: React + Material UI + Zustand + Vitest; роутинг с защищёнными маршрутами.
