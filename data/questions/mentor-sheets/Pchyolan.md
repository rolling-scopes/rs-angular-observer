# Pchyolan — JustBuildIt

**Tech:** Netlify

## Context (read before the call)
- Реализовывала Quiz Widget в рамках универсального Widget Engine — движка, который получает данные виджетов через API в формате JSON-схемы, а не хранит их на фронтенде.
- На старте проекта столкнулась с незнакомыми концепциями: Strategy Pattern, generics, discriminated unions — испытывала растерянность от масштаба архитектуры.
- Повторяющийся паттерн на протяжении всего проекта: недооценка сложности задачи → застревание → выход через декомпозицию (начать с одного виджета, а не охватывать весь движок).
- Поняла цепочку данных в проекте: mock-данные → validator → verdict — это был конкретный момент прояснения архитектуры после разговора с напарницей.
- Освоила деплой через Netlify как реальный production-процесс, не просто «залить файлы».
- Работает в команде где напарница Аня отвечала за базовую архитектуру и setup — студентка входила в уже заложенную структуру и разбиралась с чужим кодом.
- Склонна к самокритике и сравнению себя с более опытными — преодолевала тревогу через тактику малых шагов.
