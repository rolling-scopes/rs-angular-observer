# yermekyerden — Typocalypse

**Tech:** CI/CD, GitHub Actions, JWT, Jest, NestJS, Prisma, Tailwind, TypeScript, Vite, Vitest

## Context (read before the call)
- Тимлид с первого дня: взял на себя репозиторий, ветки (main/develop/diary), README, branch protection и CI/CD ещё до того, как команда начала писать код.
- Построил масштабную систему документации: ADR-фреймворк, глоссарий, domain/UI guidelines, спецификацию terminal engine, правила VFS/детерминизма/sandboxing — далеко за пределами типичного для курса.
- Принял осознанное архитектурное решение: hash-routing вместо history routing для деплоя на GitHub Pages, GitHub Actions вместо npm-пакета gh-pages — оба с явным анализом trade-offs.
- Открыто зафиксировал выгорание в дневнике: низкая мотивация, сомнения в ценности курса, решение не работать бесплатно сверх нормы — признал размер команды как главную ошибку старта.
- Последняя реализованная фича: AI-ассистент на NestJS (AssistantModule) с защищённым эндпоинтом POST /assistant/attempts/:attemptId, интеграция OpenRouter через бэкенд (ключ не попадает на фронт), JWT-аутентификация по всей цепочке.
- После ревью ментора добавил unit-тесты для AssistantService и OpenRouterClient; всю цепочку вручную прогнал через Swagger.
- Параллельно с кодом тащил организационную нагрузку: разрешал merge-конфликты, ревьюил PR тиммейтов, вёл процессы командой.
