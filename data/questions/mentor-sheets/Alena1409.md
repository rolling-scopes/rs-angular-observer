# Alena1409 — ngKittyDebug

**Tech:** Angular, Firebase, Groq, NestJS, Netlify, OAuth, Taiga UI, TypeScript, i18n

## Context (read before the call)
- Построила полноценный прототип игры в тестовом репозитории ещё до готовности основного — потратила 8+ часов и ночь, чтобы не тормозить команду.
- Провела практическое сравнение ChatGPT, Claude и Gemini для генерации игровых ассетов и самостоятельно подобрала инструмент под конкретную задачу.
- Интегрировала Groq для голосового ввода и проверки ответов; осознала, что AI-логика с API-ключами не должна жить на фронтенде — предложила перенести на NestJS.
- Страница логина переписывалась ~10 раз из-за постоянных изменений требований и слепого доверия AI code review, который незаметно сломал рабочий код.
- Спроектировала двуязычную структуру данных для бэкенда под требования i18n.
- Переход от мок-данных к реальным данным Firebase решила через частично опциональные интерфейсы — постепенная миграция без жёсткого рефакторинга.
- Последние недели: базовая версия игры готова; голосовой ввод через Groq отложен — ждёт апрува части с AI-проверкой ответов.
