# annaDzig — SAA Cat

**Tech:** Firebase, React, Render, TypeScript, Vite

## Context (read before the call)
- Построила полную Firebase Auth интеграцию с layout-based роутингом: три группы маршрутов (публичные, только для гостей, защищённые) через AuthGateLayout / ProtectedLayout / GuestOnlyLayout.
- Дважды переписывала роутинг: сначала refactored на createBrowserRouter при подключении Firebase, затем снова — с wrapper-based на layout-based архитектуру.
- Провела 6+ часов за изучением onAuthStateChanged и session restoration до написания кода — подход «сначала разобраться, потом писать».
- Пережила классический routing debugmarathon: одновременно два файла App.tsx в разных папках, смешанные BrowserRouter и RouterProvider, забытый return в компоненте.
- Хранит контент (JS-темы) в Firebase Firestore в формате Markdown — решила проблему экранирования внутри JSON, отказавшись от него.
- Столкнулась с несовместимостью версии Node и Vite, с проблемой имени ветки при git push, с TypeScript-ошибками при динамическом доступе к ключам маппинга иконок.
- Проект — образовательная платформа по JavaScript, задача студентки — фронтенд + Firebase-интеграция; деплой на Render.
