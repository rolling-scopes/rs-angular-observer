# amelur — Т-8

**Tech:** ESLint, Supabase, TypeScript

## Context (read before the call)
- Реализовал полный auth flow самостоятельно: страница регистрации с валидацией, OAuth через Google и GitHub, интеграция Supabase с RLS политиками и триггером автосоздания профиля.
- В ходе проекта переключился с Firebase на Supabase — уже после старта разработки.
- Апрувил PR с роутером на классах + чистом JS не вникая в код, затем сам оказался с этим кодом и долго страдал от последствий — повторялось несколько раз.
- Изначально голосовал против классов (нет опыта), но в итоге сам перешёл на классы для страницы авторизации ради совместимости с командным роутером.
- Хронический конфликт с ESLint (плагин Unicorn) и форматтером, ломающим окончания строк — все файлы попадали в stage.
- Проблема с типизацией Supabase: соотношение 30 мин на код → 120 мин на исправление TS + ESLint ошибок; использовал AI для фикса, получал незнакомый код.
- Осознал реальную цену code review вслепую — эволюция от «апрую не вникая» до понимания, что это системная проблема в учебной среде.
