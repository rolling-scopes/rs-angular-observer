**Tech:** Docker, ESLint, Husky, Next.js, Node.js, React, Tailwind, Vercel, Vite

## Context (read before the call)
- Единственный backend-разработчик в команде — взял на себя .NET API + Swagger, Docker, CI/CD и всю инфраструктуру проекта в одиночку.
- Начал на Vite, потратил около суток на настройку, затем полностью пересобрал проект на Next.js.
- Впервые работал с Docker: поднял контейнер на Ubuntu VPS, разбирался с SQLite volumes — классический инсайт про персистентность данных получил на практике.
- Длительная (так и не решённая) борьба с Husky-регуляркой для коммит-нейминга — сдался из-за специфичного синтаксиса.
- Столкнулся с различным поведением ESLint/Prettier в AstroNvim и VS Code — неожиданная боль из-за конфликта инструментов.
- Осваивал Next.js routing и SSR в бою: спотыкался на 404-страницах с нестандартным роутингом и библиотекой локализации.
- Имеет .NET-бэкграунд — намеренно опирался на знакомые паттерны, чтобы быстрее освоить фронтенд-стек.
