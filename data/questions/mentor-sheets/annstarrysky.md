# annstarrysky — 111 Blind Kittens

**Tech:** Ant Design, Next.js, React, Tailwind, Vite

## Context (read before the call)
- Автоматически назначена тимлидом — охотно приняла роль, самостоятельно настроила Kanban с labels, организовывала созвоны и объясняла процессы команде.
- Стек изменился в самом начале: команда стартовала с Vite, перешла на Vue по совету ментора бэкендера Юры, позже фронтенд освоил React/Next.js — для студентки это первый опыт с фреймворками.
- Классический over-engineering новичка: потратила много часов на 3D SVG-кнопку через ChatGPT и псевдоклассы — выглядела красиво, но была полностью нефункциональна; переделала по совету ментора.
- Проект — обучающее приложение с компонентом словарика (список тем, скрывается после выбора), дашбордом и планируемым тренажёром.
- Придумала дизайн-концепцию с маскотом-кошкой, включая белых котиков для тёмной темы; активно использует ChatGPT для контента и генерации ассетов.
- К концу проекта почувствовала, как «кликает» React — осознала разницу между скоростью вёрстки по-старому и компонентным подходом, открыла для себя встроенный роутинг Next.js.
