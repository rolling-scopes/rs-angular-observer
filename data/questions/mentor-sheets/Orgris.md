# Orgris — Auto-Team 9

**Tech:** CI/CD, Firebase, OAuth, React, Tailwind, TypeScript, Vite

## Context (read before the call)
- Архитектурный лидер команды — самостоятельно исследовал варианты бэкенда, выбрал Firebase и разработал детальный концепт приложения с геймификацией, UX-структурой всех экранов и игровыми механиками
- Проект — игровое приложение для изучения хард-скиллов (механика настолки с кубиками), цепочка уровней в стиле Duolingo с подбором вопросов по сложности
- Реализовал полный Auth-слой: Firebase Auth + Firestore, кастомный хук для получения свежих данных пользователя, protected/public routes
- Столкнулся с конфликтом DoodleCSS и Tailwind — цвета были захардкожены в библиотеке и перезаписывали стили, решил вендорингом; вынес как принцип: сразу изучать библиотеку, не искать лёгкий путь
- Создал переиспользуемый компонент для уведомлений и состояний загрузки
- На момент последней записи работает над главным экраном выбора уровней и проектирует слой состояния (modal-like store) для передачи данных в Game-компонент
