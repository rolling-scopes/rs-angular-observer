**Tech:** ESLint, Husky, JWT, Netlify, SCSS, Supabase, TypeScript, Vite

## Context (read before the call)
- Потеряла первую неделю из-за дисфункциональной первой команды — самоназначенный тимлид запретил ей трогать фронт, ограничив только бэком; ушла и начала заново с новым партнёром.
- Единолично настроила весь проект с нуля: Vite + TypeScript + ESLint + Prettier + Husky + SCSS, GitHub Project с Kanban-доской, шаблоны MR и Issue.
- Реализовала Supabase-бэкенд с JWT-авторизацией, собрала отдельную API-тестовую страницу для проверки интеграции.
- Систематически декомпозировала Memory Game на 7 фазовых GitHub Issues с помощью AI — сравнила несколько LLM и выбрала DeepSeek как наиболее полезный инструмент для архитектурного планирования.
- Столкнулась с устаревшей документацией Supabase: версии расходятся между туториалами и актуальным API, нашла точку входа только после глубокого исследования.
- Работала в условиях выгорания, частичной смены команды и внешних обстоятельств (отмена рейсов, VPN-блокировки) — проект был поднят и стабилизирован вопреки этому.
- Инициативна: напрямую связалась с автором задания (Димой), когда в первой команде зашла в тупик, и самостоятельно сформировала альтернативные планы реализации.
