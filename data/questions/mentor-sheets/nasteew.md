# nasteew — Алекс и его друзья

**Tech:** CI/CD, ESLint, GitHub Actions, JWT, NestJS, Prisma, React, Supabase, Vercel, Zustand

## Context (read before the call)
- Тимлид без опыта бэкенда подняла весь бэкенд в одиночку: NestJS + Prisma, JWT с refresh-токенами в куках, Swagger-документация, профиль пользователя — несколько сессий по 10 часов.
- Настроила весь проектный инструментарий с нуля: CI/CD (GitHub Actions → Vercel), ESLint/Prettier с pre-commit хуками, GitHub Projects с задачами и ветками для всей команды.
- Повторяющийся баг с .env (секретный ключ не читался, JWT тихо ломался) преследовал несколько недель подряд и провоцировал полные переписывания сервиса.
- Самостоятельно исследовала стратегии хранения refresh-токенов (куки vs LocalStorage, ротация, однократное использование), верифицируя рекомендации через независимые источники.
- Сравнила 3 платформы для хранения аватаров, выбрала Supabase — реализовала полный цикл: загрузка, публичные ссылки, сохранение в БД.
- Реализовала Google OAuth через popup-окно (бэкенд отдаёт HTML-страницу вместо скрипта) — самостоятельно заметила потенциальную уязвимость и придумала митигацию.
- По ходу проекта пришла к архитектурному инсайту: три API-маршрута объединила в один; также обнаружила, что бэкенд оказался интереснее, чем ожидала.
