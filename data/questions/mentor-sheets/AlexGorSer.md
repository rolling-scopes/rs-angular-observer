# AlexGorSer — ngKittyDebug

**Tech:** Angular, ESLint, Firebase, JWT, NestJS, Netlify, OAuth, PostgreSQL, Prisma, Render, Supabase, TypeORM

## Context (read before the call)
- Единственный бэкенд-разработчик в команде — взял на себя полную ответственность за серверную инфраструктуру с первой недели.
- Построил бэкенд на NestJS + Prisma ORM + Supabase PostgreSQL; сознательно отверг Firebase Auth и Supabase Auth в пользу собственной реализации JWT с refresh-токенами в httpOnly-куках.
- Настроил полный CI/CD: GitHub Actions для CI, Render для деплоя бэкенда, Netlify с preview-деплоями для фронтенда; CORS с regex под динамические preview-URL.
- Потерял ~2 дня на проблемы с Prisma ORM (path resolution, test mocking) — Google, AI и официальная документация давали только костыли; решение нашёл на официальном Discord NestJS.
- Провёл глубокое исследование микросервисов, gRPC и Kubernetes перед тем как принять обоснованное решение остаться на монолите.
- На старте проекта выполнил подробный анализ рисков двух вариантов задания — идентифицировал бэкенд как «бутылочное горлышко» и аргументировал выбор в пользу модульной архитектуры.
- Также терял время на проблемы с подключением к Supabase (предположительно VPN/сетевые ограничения).
