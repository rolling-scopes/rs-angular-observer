# isaluk — Auto-Team 4

**Tech:** Render, TypeScript, Vite

## Context (read before the call)
- На старте проекта (день 1) самостоятельно проанализировала идею тимлида и выявила архитектурный риск: простой MVP (роутинг + localStorage + fetch к LLM) не даст каждому участнику реализовать 2 сложных Feature Component — обязательное условие допуска к защите.
- Спроектировала и предложила команде модульную систему рендеринга задач: LLM получает специфичный промпт и возвращает структурированный JSON, фронтенд динамически отрисовывает интерактивный UI (квизы, Drag&Drop) — вместо простого чата.
- Реализовала Store на Observer pattern с использованием замыканий (closures) вместо классов — осознанное решение для гарантированной инкапсуляции приватного состояния; использовала Partial<T> для частичных обновлений и Set вместо Array для подписчиков (O(1) отписка).
- Обнаружила и задокументировала «ловушку F5»: watchAuth при любом обновлении страницы перекидывает пользователя на #/dashboard, что делает невозможным обновление страницы во время игры — запланировала починку роутинга.
- Реализовала валидацию формы авторизации с debounce (300мс) и маркером touched, чтобы ошибки показывались только после того, как пользователь коснулся поля; разбила монолитный authScreen.ts на отдельные функции.
- Нашла дублирование логики между initAuth и watchAuth — запланировала рефакторинг с разграничением ответственности этих функций.
- Самостоятельно изучила Vite с нуля до начала разработки; проект деплоится на Render.
