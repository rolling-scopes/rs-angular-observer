# solarsungai — RSSAgents

**Tech:** CI/CD, Canvas, Groq, Husky, PostgreSQL, React, Supabase, Vercel, i18n

## Context (read before the call)
- С первых недель взяла на себя архитектуру AI-части: самостоятельно проработала формат взаимодействия с LLM, стратегию контекстного окна и разделение данных между фронтом и бэком.
- Интегрировала Supabase (PostgreSQL + Auth) в уже работающее приложение: спроектировала схему с JSONB-полем payload для гибкого хранения разнотипных вопросов и View `questions_public`, скрывающей правильные ответы от фронтенда.
- Решила нетривиальную проблему: JavaScript-массивы не проходили в PostgreSQL-функцию как TEXT[] — заменила тип параметра на JSONB, чтобы сравнение шло как JSON с обеих сторон.
- Реализовала мультиязычное хранение контента прямо в JSONB-payload (`{"ru": ..., "en": ...}`), совместив с уже настроенным i18next без изменения схемы базы.
- Самостоятельно спроектировала детальный spec для AI-виджета: два режима (Interviewer/Teacher), Stress Mode с таймером, PDF-экспорт, голосовой ввод, Code Runner, Skill Map — большая часть осталась на уровне дизайна.
- Несколько раз оказывалась в ситуации дублирования: делала страницу, которую параллельно делал другой участник команды; команда строила страницы без общей дизайн-системы, потом переделывала.
- Неоднократно анализировала трейдофф локальная LLM vs. облачный API (Groq/Gemini) — взвешивала баллы за сложность против качества и простоты, в итоге выбрала облако.
