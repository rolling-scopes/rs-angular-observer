# devenrgy — Tandem Trauma Team

**Tech:** Tailwind, Vite

## Context (read before the call)
- Отвечает за весь фронтенд в одиночку — инициализировал проект с нуля на bun + Vite, настраивал стек самостоятельно.
- Выбрал амбициозный набор инструментов для новичка: Tailwind, HeroUI, TanStack Router, Biome — сразу всё вместе.
- Применил FSD (Feature Sliced Design) как архитектурную методологию — это сложная структура, нетипичная для первого проекта.
- Судя по дневнику, открытие команды bun add и флага -d было значимым событием — уровень опыта очень начальный.
- Основная командная проблема с самого начала — несовпадение расписаний для созвонов, координация давалась с трудом.
- Крайне мало данных о прогрессе: единственная запись датирована началом проекта и описывает только настройку окружения.
- Разрыв между амбициозным стеком (FSD + TanStack Router) и реальным уровнем опыта — ключевой риск для глубины ответов.
