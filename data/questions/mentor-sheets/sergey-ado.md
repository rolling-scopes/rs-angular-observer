# sergey-ado — Nova

**Tech:** Docker, Express, JWT, Jest, NestJS, Node.js, PostgreSQL, Prisma, Render, TypeScript, Vitest, WebSocket

## Context (read before the call)
- Единственный backend-разработчик в команде — поднял весь бэкенд в одиночку: Express, PostgreSQL, Prisma, Docker, Render, JWT, Socket.io.
- Перед тем как трогать командный репо, провёл полноценный proof-of-concept в личном репо — методичный, осторожный подход.
- Сделал осознанный технологический выбор с обоснованием: Express вместо NestJS (меньше эндпоинтов, меньше оверхеда), Socket.io вместо чистого WebSocket (совместимость с браузерами, кастомные типы сообщений).
- Persistent blocker: Render-hosted Postgres недоступна с локальной машины — в итоге переосмыслил это как фичу безопасности, а не баг.
- В середине проекта открыл для себя Zod для валидации запросов — заменил ручной парсинг, был искренне воодушевлён.
- Прошёл через множество итераций деплоя на Render с переписыванием скриптов и чтением логов; зафиксировал необъяснённый ночной spike латентности 2s vs <0.5s.
- В code review ловил неявный any и проблемы с регулярками (кириллица в паролях, отсутствие флага i).
