# WhaleisaJoy — ngKittyDebug

**Tech:** Angular, CI/CD, ESLint, Firebase, Husky, Netlify, RxJS, SCSS, Taiga UI, Tailwind, i18n

## Context (read before the call)
- Де-факто тимлид команды: единолично инициализировала проект, настроила eslint/husky/commitlint/branch validation/routing/CI/CD и Netlify SPA config для монорепозитория, ведёт командную вики.
- Глубоко освоила Taiga UI: прошла путь от хардкодного кастомного компонента до правильного использования appearance API — ключевое техническое открытие за проект.
- Решила нетривиальную проблему совместимости LESS и SCSS в Taiga UI: установила LESS рядом с SCSS как pragmatic fix.
- Столкнулась с багом Transloco: scope names конвертируются в camelCase, что вызывало silent failures в переводах на уровне страниц.
- Обнаружила ограничение Angular: SCSS/CSS-переменные нельзя использовать в media queries напрямую — пришлось отказаться от паттерна.
- На последнем этапе реализует: игровую механику с пулами задач по сложности (easy/medium/hard), debounce-логику для loader (не показывать при быстрой загрузке, минимум 400ms если уже показался), загрузку аватарки через внешний image host.
- Предложила AI-сгенерированный дизайн, который команда приняла целиком — влияние выходит за рамки технических решений.
