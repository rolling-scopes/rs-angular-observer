# Khabib1802 — DevCraft

**Tech:** ESLint, Husky, React, Redux

## Context (read before the call)
- Занимался настройкой всей инструментальной базы проекта: ESLint + Prettier + Husky с pre-commit хуком на staged-файлы, плюс плагины для сортировки импортов.
- Построил библиотеку базовых UI-компонентов: Button (2 варианта, 2 размера), Input (label + hint + error), Loader (3 размера, currentColor), Logo с роутинговым Link.
- Использовал TypeScript-интерфейсы ButtonHTMLAttributes / InputHTMLAttributes — компоненты наследуют нативные атрибуты без ручного перечисления.
- Столкнулся с forwardRef при интеграции React Hook Form — до этого не знал, что ref нельзя передать как обычный проп.
- Применил useId для автоматической связки label↔input вместо ручного id, clsx вместо шаблонных строк для условных классов.
- Redux есть в стеке, но в дневниках пока виден только слой UI — как компоненты интегрированы с Redux-стором, стоит уточнить на защите.
- Судя по дневникам, работал в связке с React Hook Form — форма была одним из первых реальных потребителей компонентов.
