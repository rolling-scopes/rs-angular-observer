# Peccopa — Nova

**Tech:** Husky, Render, Tailwind, Vitest, i18n

## Context (read before the call)
- Построил с нуля ComponentsAPI на vanilla TypeScript — базовая система компонентов с иерархией, менеджерами и полной документацией, две недели работы.
- Самостоятельно реализовал Redux-подобную StateAPI (store, dispatcher, reducer, middleware, afterware) без готовых библиотек — оригинальный подход пришлось бросить и переписать на реактивную модель с afterware.
- Классический оверинжиниринг-кейс: декомпозировал один файл BaseComponent на 8 по принципу SRP, без новой функциональности — сломал все внутренние связи и восстанавливал их целый день.
- Тесты для древовидных менеджеров компонентов написать не смог — строгая типизация TS потребовала бы полного графа mock-данных, задачу признал нерешаемой и переключился на другое.
- Проактивно вышел за рамки своих задач: создал систему GitHub Issue templates с авто-именованием веток, по пути обнаружил изменение API (required → validations: { required: true }).
- Реализовал i18n с переключением языков; в последних итерациях делал страницу About Us и начал Sound Manager.
- Осознанно сформулировал инсайт о командной работе: ~50% времени уходит на ожидание ревью и мержей.
