# 27moon — RSSAgents

**Tech:** TypeScript, i18n

## Context (read before the call)
- Взяла на себя всю i18n-архитектуру проекта: двухуровневая локализация — JSON-файлы для строк интерфейса и тип LocalizedString для виджетов.
- Расширила TypeScript через declare module для генерации автодополнения ключей перевода в IDE — нестандартное, самостоятельно найденное решение.
- Выбрала Mantine как UI-библиотеку, настроила централизованный MantineProviderWrapper и собрала единую систему дизайн-токенов (spacing, radius, line-height) для стандартизации стилей в команде.
- Провела болезненную борьбу с ограничением Mantine — обязательная палитра из 10 оттенков при реальной потребности в 1-2 цветах — и решила через CSSVariablesResolver.
- Приняла осознанное архитектурное решение по i18n: отказалась от i18next-http-backend в пользу прямого импорта, выбрала resolvedLanguage как источник правды о текущем языке.
- Взяла ответственность за унификацию расходящихся стилей разных членов команды.
- С первых дней участвовала в дизайне страниц Dashboard и Login, координировала решения через командные встречи.
