## Context (read before the call)
- Взял AI Chat как личный компонент-вызов — намеренно выбрал незнакомые технологии (Angular, локальный LLM), стартовал с нуля без опыта во фреймворке.
- Построил полный pipeline интеграции с локальной Ollama/Gemma3: типизированный API слой, стриминговые ответы, кастомная Angular директива для markdown-рендеринга в реальном времени.
- Использовал Angular DI как стор вместо NgRx — осознанное командное решение, с явным расчётом на будущий перенос логики на бэкенд.
- Потратил несколько часов на реализацию ControlValueAccessor для форм, пока не обнаружил, что Angular signal forms решают задачу элегантнее — классический пример 'дорогого открытия'.
- Потерял значительное время на баг с `display: inline` у `:host` в Angular — ширины не применялись нигде, причина нашлась только через DevTools.
- Продуктовая идея: 'Звонок другу' в квизе, где ошибки слабой бесплатной модели — намеренная фича, вынуждающая пользователя думать критически, а не слепо доверять.
- На момент последней записи: рефакторинг бэкенда, в планах — выбор модели в профиле пользователя и история сообщений с чатом.
