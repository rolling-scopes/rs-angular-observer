**Tech:** GitHub Actions, SCSS, Supabase, TypeScript

## Context (read before the call)
- Взяла на себя всю фундаментальную архитектуру с нуля: SPA-роутер, App Core, навигация, mock-аутентификация — сдала одним массивным PR как первый вклад в проект.
- Приняла решение отклонить рабочий PR тиммейта, потому что тот использовал class-компоненты — команда договорилась о функциональном стиле и переписала основу заново.
- Потеряла несколько сессий на конфликт macOS case-insensitive filesystem vs Git: ветка 'Feature/' vs 'feature/' создавала фантомный дубль; в итоге решила полным re-clone репозитория.
- Первый опыт командной разработки — открыто рефлексирует про коммуникационный паралич ('глухой телефон') и в итоге разблокировала себя, просто начав писать код вместо ожидания консенсуса.
- В последних PR занималась рефакторингом логики: разделила ответственность между Library (выбор параметров) и Practice (загрузка данных), централизовала обработку API-ошибок через withApiErrorHandling, использовала Error.cause для сохранения оригинальной ошибки.
- Приложение — квиз/обучающий продукт с Supabase-бэкендом; студентка работала преимущественно на фронтенде: роутинг, state, UI-архитектура, обработка ошибок.
