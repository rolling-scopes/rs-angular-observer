# anelka777 — Gang of Four

**Tech:** Material UI, React

## Context (read before the call)
- Разрабатывает игровой виджет-тренажёр (matching/quiz) с уровнями, прогрессом и навигацией — стек React + Material UI + Firebase.
- С первых дней взяла на себя роль архитектурного лидера: самостоятельно сделала Figma-макет Dashboard и предложила структуру папок до начала разработки.
- Придумала и реализовала стратегию мок-данных, чтобы разблокировать фронтенд пока бэкенд не был готов.
- Подключила реальный API через кастомный хук, попутно выровняв типы фронтенда с бэкендом — это затронуло несколько компонентов.
- Провела рефакторинг слоя данных: разделила MatchingData и пропсы компонентов, добавила TOPIC_LABELS и состояние Completed.
- Реализовала навигацию по уровням, прогресс-трекинг и вынесла логику в отдельный компонент LevelGame.
- Осознанно ставит архитектурные вопросы раньше команды — это сильная сторона, стоит проверить глубину понимания за словами.
