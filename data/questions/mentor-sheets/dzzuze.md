# dzzuze — SAA Cat

**Tech:** GitHub Actions, React, Tailwind

## Context (read before the call)
- Организационная роль с первого дня: настроил Jira-доску, распределил задачи и созвонился с командой ещё до написания первой строчки кода.
- Работает над auth-зависимым UI: хедер, пользовательское меню, страница с информацией о пользователе, кнопка Sign Out.
- Команда прошла через осознанный дизайн-выбор: отобрали один вариант из ~10, остановились на тёмной теме с серо-жёлтыми акцентами и переключили язык приложения на английский.
- Столкнулся с проблемой роутинга при реализации навигации для авторизованных пользователей — разобрался самостоятельно.
- Пишет тесты для хедера: потратил время на отладку, сам удивился почему старые тесты проходили при сломанной логике.
- Стек: React + Tailwind + GitHub Actions (CI/CD), управление задачами через Jira.
