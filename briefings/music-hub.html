Project

App: NgMusicFlow — Angular 21 SPA + NestJS backend for music discovery and streaming via the https://jamendo.com">Jamendo API. Live deploy: https://ng-music-flow.netlify.app/discover/popular

Stack: Angular 21 (Zone mode), NgRx SignalStore, SCSS + Tailwind CSS, Vitest + Playwright (Browser Mode), NestJS + TypeORM + Passport JWT, Husky + Lint-staged + Semantic Release, GitHub Actions CI.

Repo: https://github.com/evgeniia-korolova/ng-music-flow Created: 2026-05-09 | Last push: 2026-06-15 | Default branch: dev (GitFlow) | Open issues: 9

Architecture choices worth noting: Feature-Sliced Design (FSD) chosen for folder structure. Full-stack monorepo (client/ Angular + api/ NestJS). SignalStore used as primary state layer. InjectionToken for TRACK_DATA_PROVIDER to decouple TracksStore from individual components. Netlify deploy with proxy to keep Jamendo API key server-side only.
