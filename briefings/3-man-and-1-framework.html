What he built (from PR #56 + auth branch commits):

Reads existing token from localStorage on init.
  • DummyBackendInterceptor: Functional HTTP interceptor intercepting /auth/login, /auth/register, /auth/me, /keys endpoints and returning mock HttpResponse with delay(). Clean implementation using of() + delay().
  • LoginForm component refactor: Migrated to reactive forms using FormBuilder, Validators.required + Validators.email + Validators.minLength, signal inputs (input<string>()), output() emitter. Separated form logic from page.
  • Initial login page stub (commit init: login, 2026-05-18): The first functional piece in the repo — he bootstrapped the login UI before yuriyli's sprint-1 components PR.

What is missing / concerning:

  • PR #56 has been OPEN since 2026-06-03 — 12 days unmerged at snapshot date. No review comments visible. Not merged to main or dev. The fix commit on 2026-06-05 (fix: login form) suggests he did react to something, but then stopped.
  • Zero diary entries — the development-notes/nakurienota/ folder on main contains only a .gitkeep. No diary was ever merged. He loses diary points entirely.
  • Git commits use local username stenyukovs rather than the GitHub login nakurienota, which creates a disconnect in contribution tracking.

Level: The AuthService and interceptor code is reasonably clean — signals used correctly (writable vs readonly signal separation is the right pattern), HTTP interceptor is idiomatic Angular. The reactive form usage in LoginForm is correct. However, the evidence base is thin: this is ~200 lines across 3 files. Cannot tell if he understands the full picture or followed a tutorial pattern.

Probe questions for the interview:

  • Can-you-create-it test: Ask him to re-implement AuthService.login() from scratch — the RxJS chain, the tap side-effect, the signal update. This is the piece most likely to be his own work; see if he can explain each step.
